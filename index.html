Quick Start Installation Guide

Install and run Version 1 in production mode using Node.js (>= 18.0.0).

# Navigate to V-1 directory cd V-1 # Install package dependencies npm install # Copy environment configuration cp .env.example .env # Configure environment keys (e.g. GROQ_API_KEY) # nano .env # Launch bot in production mode npm start

Setup Version 2 with MariaDB backend, TypeScript compilation, and automated tests.

# Ensure MariaDB server is active on port 3306 # Import database schema: # mysql -u root -p < V-2/sql/schema.sql # Navigate to V-2 directory cd V-2 # Copy environment configuration cp .env.example .env # Install dependencies & build source npm install npm run build # Run unit tests npm test # Launch production process npm start
dashboard

Local Operations & Dashboard (V-2)

Version 2 hosts a local background monitoring HTTP server bound strictly to the loopback interface (127.0.0.1) for real-time status inspecting and control.

GET http://127.0.0.1:8787/health

Health check endpoint for process supervisors and container liveness probes.

GET http://127.0.0.1:8788/api/status

Detailed operational telemetry, socket state, message throughput, and MariaDB pool metrics.

POST http://127.0.0.1:8788/api/trusted

Modify trusted owner/admin entity rules dynamically via bearer token authentication.

PM2 pm2 start ecosystem.config.cjs

Production process management with automatic restarts and log rotation.

security

Security & Data Privacy Directives

warning
Session Credentials Protection
Never commit or share folders containing auth_info/ or auth_info_baileys/. These directory structures hold raw RSA keypairs and authentication tokens granting complete access to your WhatsApp session.
lock
Loopback Binding Constraint
Ensure health and monitoring ports (8787 and 8788) remain bound strictly to 127.0.0.1. Do not expose administrative ports to public networks without HTTPS and bearer tokens.
gavel
Compliance & Responsible Use
Execute automated message handling strictly in accordance with local regulations, recipient consent, and WhatsApp's official Terms of Service.
